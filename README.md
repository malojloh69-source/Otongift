# OtonGifts 6.0

Чёрно-синий Telegram Mini App с кейсами, общей Crash-комнатой, обычными подарками и виртуальными коллекционными экземплярами. Один Python-процесс в `main.py` отдаёт страницы из `dist/` и выполняет API, бот и игровую логику. Flask не требуется. Корневой `index.html` — автономная демоверсия, которую можно собрать локально командой `python tools/build_html.py`. Она больше 60 МБ и не хранится в этом репозитории; сервер работает с `dist/`.

На стартовой вкладке «Игры» доступны кейсы, апгрейды, Краш и рефералы. Здесь расположен розовый баннер «Открывай кейсы и находи своё»; в разделе «Кейсы» — отдельный широкий баннер «Кейсы / Открывай кейсы и выбивай редкие подарки». Секция игр частично перекрывает домашний баннер, карточки заполняются изображениями. Загрузка использует масштабируемый векторный знак OTON на чёрном фоне.

## Локальный запуск

Нужен Python 3.11+. Сторонних Python-пакетов нет.

```bash
python main.py
```

Открой `http://127.0.0.1:3000`. По умолчанию `DEMO_MODE=true`: новый игрок начинает с **0 Stars, 0 GRAM и пустым инвентарём**. Для проверки доступны тестовое пополнение и админ-панель. База создаётся в `data/game.sqlite3`. Перед обновлением существующего проекта сделай копию SQLite-базы; миграции добавляют нужные поля и таблицы без удаления инвентаря.

## Bothost

1. Используй файлы этого репозитория как корень проекта. Файл входа — `main.py`. `dist/` хранит сайт, `main.py` обслуживает сайт и API. Большой корневой `index.html` исключён из GitHub; для самостоятельного офлайн-просмотра его можно собрать локально командой `python tools/build_html.py`. Сервер отдаёт `dist/index.html`.
2. При создании бота включи **«Использовать домен»** и выбери `main.py` как главный файл. Сервер слушает `0.0.0.0`, порт берёт из переменной Bothost `PORT` (по умолчанию 3000). `Dockerfile` использует тот же порт; `requirements.txt` пуст, потому что код использует стандартную библиотеку.
3. Для настоящей авторизации Telegram заполни переменные окружения по `.env.example`: `DEMO_MODE=false`, `BOT_TOKEN`, `BOT_USERNAME`, `MINI_APP_URL=https://bot-<ID>.bothost.tech`, `RUN_BOT_POLLING=true`, при необходимости `ADMIN_IDS`. Для Stars-платежей дополнительно `ENABLE_STAR_PAYMENTS=true`, действительный `TERMS_URL` и `SUPPORT_CONTACT`. Настрой у бота корректный Mini App URL и платежные команды `/terms` и `/paysupport`. Замени пример условий и контакта своими правилами до включения оплаты.
4. Сохрани `data/game.sqlite3` на постоянном диске Bothost. На одной SQLite-базе должен работать **один** экземпляр бот-поллинга. После деплоя проверь `/api/health`, запуск Mini App из бота и пробный платёж Telegram.

При `/start` бот отправляет баннер `dist/assets/promos/oton-welcome.png` с приветствием и синей inline-кнопкой «🚀Играть», открывающей `MINI_APP_URL`. Изображение загружается непосредственно в Telegram при отправке сообщения. Команда администратора `/ClezzyKryt` сохраняет отдельный вход.

`BOT_TOKEN` не вкладывай в ZIP или репозиторий. `.env.example` содержит только шаблон. Установленный `PORT` и хост можно менять локально. Bothost-документация: <https://bothost.ru/docs/web-apps-domains>, <https://bothost.ru/docs/domains-and-ports>.

## Игровые правила

- **Кейсы:** 19 заполненных кейсов. Выпадают только обычные подарки или приз на баланс (суммарный шанс валютного приза в каждом кейсе 5%). Если кейс оплачен Stars, валютный приз начисляется в Stars; если GRAM — в игровых GRAM по конфигурационному курсу. Вероятности показаны на странице кейса и совпадают с серверными весами. Сервер фиксирует приз до анимации 4,9 секунды. Результат и повтор запроса восстанавливаются.
- **Апгрейд:** рискованный обмен принимает обычный или коллекционный подарок из инвентаря; целью служит только более дорогой обычный подарок. Коллекционный экземпляр нельзя выбрать как цель. Отдельное гарантированное превращение обычного подарка в виртуальный коллекционный стоит 25 игровых Stars и выбирает случайные модель, фон, узор и свободный номер коллекции. Уникальность `(collection_id, number)` защищена SQLite и транзакцией.
- **Crash:** общая серверная комната, поля суммы с `−`, `+`, `MAX`, выбор Stars, GRAM или подарка из инвентаря и автовывод. При ставке подарком экземпляр резервируется; на выводе он расходуется и выдаётся **другой обычный, неулучшенный подарок** с игровой ценой не выше оценки ставки × множитель. Выбор подходящего подарка детерминирован: самый дорогой из доступных обычных, кроме исходного. Коллекционный подарок не выпадает. Валюта нового подарка наследуется от поставленного. При краше подарок сгорает. При денежных ставках выплата остаётся в валюте ставки. Результаты и экземпляры сохраняются транзакционно, повтор вывода не создаёт второй приз. Кнопка ставки жёлтая для Stars и подарков за Stars, синяя для GRAM и подарков за GRAM. Стартовый экран использует присланный силуэт Пепе и переход к каркасу интерфейса без текста о подготовке Crash. Автономный HTML показывает только собственную локальную ставку.

Подарок, полученный за GRAM, показывает цену в GRAM; за Stars — в Stars. В магазине можно выбрать валюту перед покупкой. Внутренняя оценка хранится также в Stars для сопоставления призов в Crash и апгрейдах. Фоны **Black** и **Onyx Black** добавляют к игровой оценке коллекционного экземпляра 15% и 25% соответственно. Это настраиваемые игровые надбавки с учётом интереса к чёрным фонам, о котором пишет [Getgems](https://t.me/s/getgems/819), а не текущие котировки или гарантированный выкуп. Показатели атрибутов и вероятностей скрыты из интерфейса, а серверная механика выпадения сохранена.

Все игровые балансы и коллекционные предметы **виртуальные**. Это не выдача Telegram NFT и не перевод реального GRAM. Настоящих подарков в подтверждённом запасе проекта нет.

## Цены обычных подарков

Публичный подтверждённый снимок `payments.getStarGifts` от 02.10.2026 19:07:27 UTC хранится в `tools/data/gifts_api_response.json`. Он содержит цену первоначального выпуска обычных подарков, а также минимум перепродажи для коллекций, **но не содержит заявок скупки обычных подарков**. Поэтому не выдаём цену выпуска за цену скупки.

Если оператор добавит проверенную котировку в `tools/data/ordinary_buyback_quotes.json` (`telegram_gift_id`, `bid_stars`, HTTPS `source`, `observed_at`), значение и источник будут показаны как котировка. Сейчас подтверждённых заявок **0**. Обычно применяется явно обозначенная **игровая оценка** из коллекционного минимума (`max(1, floor − стоимость улучшения)` Stars): покупка обычного подарка и его улучшение вместе стоят примерно столько же, сколько минимум коллекции. Для двух коллекций без подтверждённого минимума используется та же формула с явно обозначенной игровой оценкой коллекционного подарка. Для подарков без связанного улучшенного варианта сохранена базовая цена с пометкой об отсутствии заявки. Исключение по запросу владельца: **Scared Cat стоит 20 000 игровых Stars**, коллекционный вариант 20 025. Это игровая цена, а не действующая рыночная котировка или гарантированная ставка выкупа. Историческая цена выпуска остаётся отдельным полем `telegram_stars`. Для коллекций минимум перепродажи относится к коллекции, а не к конкретному номеру.

Чтобы обновить снимок и пересчитать игровые цены и кейсы:

```bash
python tools/update_prices.py tools/data/gifts_api_response.json --observed-at 2026-10-02T19:07:27+00:00
python tools/build_html.py
```

После правок каталога перезапусти сервер. Источники медиа и снимка перечислены в `ASSET_SOURCES.json` и `CATALOG_REPORT.json`.

Команда `tools/update_prices.py` пересчитывает весь каталог и поэтому сбросит ручную цену Scared Cat и связанные веса девяти кейсов. Если запускаешь её, повторно внеси ручную игровую цену, пересчитай веса для ограничения ожидаемой стоимости и собери HTML заново.

## Пополнение и кошелёк

В рабочем режиме сервер создаёт счёт Telegram в `XTR` для выбранного игрового баланса: **1 оплаченная Telegram Star = 100 игровых Stars** или **0.8 игрового GRAM** при текущем курсе 125 игровых Stars за GRAM. Для GRAM сервер сохраняет точное начисление в счёте, округляя вниз до миллионной. `createInvoiceLink` только выдаёт счёт; баланс начисляется после проверенного `pre_checkout_query` и `successful_payment`, полученных ботом через `getUpdates`. Подтверждение браузером не принимается. Повторная доставка не начисляет баланс ещё раз, возврат отражается в базе. Без токена и настройки флагов кнопка реальной оплаты отключена; в демо пополнение явно тестовое.

TON Connect позволяет подключить кошелёк и увидеть адрес по HTTPS. Подключение не удостоверяет перевод: проект не отправляет транзакции и не начисляет игровые GRAM за криптовалюту. Пополнение игрового GRAM проводится только подтверждённым счётом Telegram Stars. Указанный пользователем курс **0.1 внешнего GRAM → 1.3 игрового GRAM** оставлен как расчётная цель, но обмен не включён. Telegram требует Stars/XTR для цифровых товаров в боте и Mini App. Платёж в реальном Telegram этим архивом не проводился: нужны твой действующий бот и настройки Bothost.

## Сборка и проверки

```bash
python tools/build_html.py
python -m unittest discover -s tests -p 'test_*.py' -q
npm ci
npm run check
npm test
```

`npm` нужен только для тестов. `dist/assets` содержит оригинальные изображения, 7 483 анимации TGS/Lottie и локальный Inter WOFF2. Автономный HTML содержит основные материалы внутри файла, остальные модели берутся из соседней `dist/assets`. Проверки описаны в `CHECKS.txt`; снимки в `verification/` относятся к более ранней версии оформления. Этот архив не публикует сайт и не содержит реальных NFT.
