# Восстановление файлов из Google Drive

Проект собран из предоставленной папки Google Drive. Первоначальная папка `dist/` перенесена в `public/` для деплоя Bothost. Модели и символы упакованы в `public/asset-packs/`, сервер сохраняет исходные URL. Для анимаций приложение использует 7 483 локальных файла `.asset.js` внутри ZIP, содержащих gzip/base64-данные; исходная выгрузка содержит только два отдельных файла `.tgs` для интерфейса. Браузер получает `.asset.js` через Python-сервер без обращения к чужим CDN.

В публичной папке отсутствовали медиа для двух моделей, имена которых оканчивались на `?`: `Wanna Play?` и `Is It Cake?`. Для них используются локальные изображения и анимации соседних моделей (`gamer_clown` и `dairy_dandy`), чтобы карточки и проверки ассетов работали без сетевого обращения. Пути этих двух медиа переименованы без `?` для совместимости с Windows. Названия, ID, вероятности, цены и игровая логика моделей не менялись. Для замены `.webp` и `.asset.js` сначала извлеки ZIP командой `python tools/pack_assets.py --extract`, затем пересобери его с `--remove`.
