# Восстановление файлов из Google Drive

Проект собран из предоставленной папки Google Drive. Архив папки `dist/` и остальные исходные файлы сохранены в исходной структуре. Для анимаций приложение использует 7 483 локальных файла `.asset.js`, содержащих gzip/base64-данные; исходная выгрузка содержит только два отдельных файла `.tgs` для интерфейса. Это штатная структура данной выгрузки: браузер загружает `.asset.js`, поэтому анимации работают без сети и без отдельных `.tgs` для каждой модели.

В публичной папке отсутствовали медиа для двух моделей, имена которых оканчивались на `?`: `Wanna Play?` и `Is It Cake?`. Для них используются локальные изображения и анимации соседних моделей (`gamer_clown` и `dairy_dandy`), чтобы карточки и проверки ассетов работали без сетевого обращения. Пути этих двух медиа переименованы без `?` для совместимости с Windows. Названия, ID, вероятности, цены и игровая логика моделей не менялись. При наличии оригинальных файлов можно заменить `.webp` и `.asset.js` для каждой модели по безопасным путям в `dist/assets/models/`.
